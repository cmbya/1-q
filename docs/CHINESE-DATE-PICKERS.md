# 中文日期控件与车票手动输入

App根视图统一注入zh_CN环境，覆盖快递新增/详情提醒、车票展示开始/结束和批量展示时间的系统日期选择器；不改变系统语言设置和快递提醒使用的设备时区。车票选择仍显式使用北京时间。

车票发车日期、发车时间、到达日期和到达时间改为按钮打开选择弹窗，日期含年份、时间24小时；确认后才写回相应草稿字符串，取消或下拉关闭不写回。空字段仍显示请选择，打开弹窗看到的默认位置不是已填写值，不能在未确认时隐式保存今天。支持清除此字段，已有必填和到达日期/时间成对校验保留。识别草稿、原始票面和持久化仍使用yyyy-MM-dd与HH:mm，无数据迁移或日期猜测。

车票组件日期显示为中文年月日，展示开始/结束的摘要也使用中文年月日。其余快递中文时间格式沿用上版；不改API原始轨迹正文和技术解析器的POSIX locale。
