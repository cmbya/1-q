# 未签收快递组件

新增独立的“未签收快递”静态组件，中号／大号，每次显示一票。运输中、派送中、待取件、异常纳入；已签收、已归档排除。按创建时间升序、ID稳定排序；自动模式显示首票。

显示公司、单号、当前状态、备注、已保存最新物流和物流时间；大号另显示最近查询时间。未查询过明确提示暂无物流，不用创建时间冒充物流时间。不展示手机号或API Key。

多票使用上一票／下一票循环浏览，回到自动清除浏览偏好。当前票签收、归档或删除后自动回到首票；过时按钮通过快照ID检查拒绝写入。切票只修改组件浏览偏好，不修改物流、取件码或提醒。当前仅一个组件类型，同类型多个桌面实例共享浏览选择。

组件不发起网络或计费查询，只读共享数据；物流需由App或快捷指令更新。点击背景打开App快递列表。没有待展示数据时保留空组件；共享读取失败明确报错，不展示私有可写回退。

旧数据缺省浏览ID为空，不需强制迁移；偏好随数据编码，备份合并时保留当前设备偏好，恢复后失效ID自动回退。现有A–J取件码及火车票组件保留。
