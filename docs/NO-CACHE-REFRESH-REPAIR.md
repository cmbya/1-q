- UAPI/Tmini 查询不再访问历史结果缓存；每次有效查询直接发起一次网络请求。没有自动重试或付费回退。

- 历史缓存文件不删除；PaidTrackingCache仅保留旧数据/尾号生命周期兼容，客户端不读取它。
