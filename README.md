# 快递管家（ParcelKeeper）1.1

一个只给自己用的 iPhone 快递记录 App。核心操作是：**复制运单号或整段物流信息 → 打开 App → 点击智能粘贴 → 确认并保存**。

## 1.1 更新

- 修复点击粘贴后偶尔出现白屏、页面没有内容的问题：改用单一数据驱动的 `sheet(item:)` 路由，不再先打开空 Sheet 再等待数据。
- 粘贴过程增加忙碌状态，防止连续点击造成重复弹窗或页面竞争。
- 粘贴失败时可以直接手动输入运单号。
- 支持一次识别多个运单并批量导入。
- 支持从整段淘宝、京东、拼多多物流文字中提取：
  - 运单号
  - 快递公司
  - 平台来源
  - 取件码
  - 待取件、派送中、已签收、异常等状态
  - 驿站或快递柜文字
- 加强手机号、订单号、身份证号等误识别过滤。
- 手动修改运单号时会重新判断快递公司。

## 已有功能

- SwiftUI 原生 iPhone App
- 系统 `PasteButton`，只有主动点击时才读取剪贴板
- 本地保存、搜索、删除、归档及重复运单拦截
- 运输中、派送中、待取件、已签收、异常等状态管理
- 备注与取件码
- 本地定时提醒
- JSON 备份导出与导入
- GitHub Actions 编译无签名 IPA

## 首次安装与共享存储

最低 iOS 17。主 App 与桌面组件必须获得同一 App Group 的真实签名授权；修改组名本身不会授予权限。重签后如未自动选定，请先打开 App → 设置 → 共享存储，按实际可访问的组选择并重连；无法访问时不要卸载或清空数据，先备份并检查签名。旧本地数据只会作为明确标记的只读历史快照显示，不能代替当前共享数据。

## 当前源码已实现（不代表本版本已运行验收）

- UAPI 原生物流查询：设置中保存本机钥匙串 Key 并同意外发，支持单票、批量及快捷指令触发；可能消耗积分，手机尾号仅本次使用。详见 [UAPI说明](docs/UAPI-INTEGRATION.md)。
- 取件码分组与静态桌面组件 A–J：先在 App 的桌面组件设置中绑定分组，不通过长按组件选组。
- 快捷指令添加/识别取件码、添加或更新快递；可选 AI 服务。具体确认、外发和验证边界见 [快捷指令说明](docs/SHORTCUTS.md) 与 [快递动作说明](docs/shipment-shortcuts.md)。
- 取件码识别按 AI 开关分流：开启时直接请求 AI，失败不回退本地规则；关闭时仅本地识别、不发起 AI 请求（备用模型尝试不属于本地回退）。App 与快捷指令保持一致。
- AI 服务设置新增取件码提示词编辑：非空且最多 12000 字符，独立保存、确认恢复默认、未保存返回提醒；下一次取件码 AI 请求起生效，无需重新编译。App 与快捷指令共用，不更改地址、Key、模型或 AI 开关；响应格式与安全校验不可编辑，不要在提示词里放 Key 或其他秘密。详见 [提示词设置说明](docs/SHORTCUTS.md#编辑-ai-取件码提示词)。
- 本地取件地点提取修复品牌前名称丢失及取件码/后续指令混入地点的问题；原文完全相同的重复通知与不同订单/多票分开处理，不因相同码就合并不同订单。歧义输入不自动保存，同组未完成的相同码仍拒绝重复写入。
- 最近代码修复尚未完成 Swift/XCTest、真实账户及本版本真机验收；旧构建通过不能替代当前版本验证。

## 在 GitHub 编译

1. 新建 GitHub 仓库。
2. 将压缩包里的所有文件上传到仓库根目录，注意 `.github/workflows/build.yml` 不能漏掉。
3. 打开仓库的 **Actions** 页面。
4. 选择 **Build Unsigned IPA**。
5. 点击 **Run workflow**。
6. 编译完成后，在本次运行页面底部下载 `ParcelKeeper-unsigned`。
7. GitHub 下载的是一层 Artifact ZIP，解压后里面才是 `ParcelKeeper-unsigned.ipa`。

IPA 是无签名版本，需要用自己的 Apple 签名方式重新签名后安装。

## 关于淘宝、京东、拼多多账号直连

这三个平台的开放接口主要面向商家、服务商和经过审核的开放平台应用，需要 App Key、密钥、授权范围和服务端回调。普通个人 App 不能只做一个网页登录，就合法、稳定地读取消费者账号的全部待收货订单。

本项目不保存淘宝、京东、拼多多密码，也不通过 WKWebView 抓取登录 Cookie 或解析私有页面。那种方式容易触发风控、随页面改版失效，也有账号安全风险。

更稳妥的后续路线：

1. 申请平台正式开放权限后通过 OAuth 接入；或
2. 验收已接入的 UAPI 查询及快捷指令自动化（不是再次开发 API 接入）；或
3. 增加订单/物流截图识别，不需要交出账号密码。

## 本地打开工程

项目使用 XcodeGen 管理工程：

```bash
brew install xcodegen
xcodegen generate
open ParcelKeeper.xcodeproj
```

最低系统版本为 iOS 17，Bundle ID 默认为：

```text
com.dinghao.ParcelKeeper
```
